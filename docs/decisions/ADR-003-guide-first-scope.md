# ADR-003: Guide-first paid, ad-free product scope

Date: 2026-09-11
Status: Accepted

## Context
The opportunity is to build a modern television guide from first principles rather than reproduce the broader content/advertising model of an existing media app.

## Decision
Teevee is a paid, ad-free, guide-first iOS/Android product for the Dutch market. Core guide use does not require an account. Product development prioritises the Guide interaction before discovery, personalisation and monetisation implementation.

## Consequences
Advertising inventory, editorial news feeds, social mechanics, streaming-catalogue breadth and engagement-maximising features are outside initial scope. Phase 1 is a Guide interaction prototype and is a mandatory quality gate before broadening the product.
